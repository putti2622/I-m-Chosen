I'M CHOSEN — website update

Deploy/update:
1. Extract this ZIP.
2. Open https://github.com/putti2622/I-m-Chosen
3. Add file > Upload files.
4. Upload index.html and README.txt at the repository root (not inside a nested folder).
5. Commit changes to main and wait for GitHub Pages to redeploy.

Song library:
- This build contains 30 verified Telugu starter song entries as independent local song records.
- Each entry has a theme-selected visual background and local lyrics editor/projection controls.
- Lyrics entered by the user are saved in local browser storage on that device only.
- A CSV importer accepts columns: number,title,language,theme.
- Themes: praise, cross, mission, prayer, hope.
- Imported CSV entries are stored locally in the browser. To publish them to all visitors, add them to the website data and upload a new index.html.

Important:
- The Christian Data House source page is titled “Vidhyarthi Geethavali (314)”. The visible list must be fully transcribed and verified before claiming all 314 titles are loaded. This package does not falsely label the 30 starter entries as a complete 314-song catalogue.
- Lyrics and recordings are not copied or redistributed. Add lyrics only when you own them or have permission. Audio links must comply with applicable licence and terms.
- The Bible section remains linked to YouVersion.
